# FreekAI landingpage

Eerste statische landingpage voor `freekai.nl`.

## Bestanden

- `index.html` — content en structuur
- `styles.css` — bunq-achtige, kleurrijke, ronde visuele stijl zonder directe kopie

## Lokaal bekijken

```bash
cd /config/clawd/freekai-site
python3 -m http.server 8088
```

Open daarna: `http://localhost:8088`

## Positionering

FreekAI Admin:
Administratie aanleveren via Telegram, met AI-controle, Informer lookup, duplicaatcheck en menselijke goedkeuring voordat er geboekt wordt.
